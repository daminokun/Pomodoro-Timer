# Pomodoro Timer App

A simple and responsive Pomodoro Timer application built with HTML5, CSS3, and JavaScript.

---

## Live Demo
Access the live app:
https://daminokun.github.io/pomodoro-timer/

---

## Features
- **25-Minute Focus Countdown**: Standard Pomodoro session length.
- **Timer Controls**: Start, Pause, and Reset functionality.
- **Clean UI**: Minimalist design centered on readability.

---

## Tech Stack
- HTML5
- CSS3
- JavaScript (`setInterval`, DOM Manipulation)
